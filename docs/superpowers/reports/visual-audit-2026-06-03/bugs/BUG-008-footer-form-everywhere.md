# BUG-008 — Лид-форма «Заполните форму, мы свяжемся для консультации» на каждой странице

| Поле | Значение |
|---|---|
| Severity | 🔵 Cosmetic (UX-полишь) |
| Страница | Все маршруты сайта (footer-уровень) |
| Скриншоты | Все скриншоты `tour/*/cart.png`, `tour/*/checkout.png`, `mobile-375/thanks-page.png`, `mobile-375/page-contacts.png` |

## Что видно

Перед футером на **каждой** странице (home / shop / product / cart / checkout / thanks / contacts / loyalty / privacy / blog / …) встроена одна и та же тёмная панель с заголовком «ЗАПОЛНИТЕ ФОРМУ, МЫ СВЯЖЕМСЯ ДЛЯ КОНСУЛЬТАЦИИ» и фото футболки PINHEAD.

На большинстве страниц это **дублирует** другие формы той же сути:
- `/contacts` — отдельный блок «контакты» + та же форма
- `/shop` — блок «Не нашли модель?» с такой же формой + та же форма ниже
- `/thanks` — пользователь только что её отправил
- `/cart` (empty) — single content на странице — что усиливает confusion (см. BUG-001)

## Где источник

Скорее всего вынесена в layout / footer wrapper. Появляется до тёмного footer'а с «ИНН / КПП».

## Что предложить

Не глобально удалять — форма приносит лиды. Но избирательно скрывать:

- На `/thanks` — точно убрать
- На `/cart` и `/checkout` — убрать или заменить на context-aware copy («Нужна консультация по заказу?»)
- На `/contacts` — оставить только основную форму контактов, эту убрать (дубль)
- На `/shop` — оставить только «Не нашли модель?» блок выше, эту убрать (дубль)

Технически: добавить prop `<Footer hideLeadForm />` либо проверять `usePathname()` в `LeadForm`.

Дополнительно: каждая инстанция формы шлёт `source` (по CLAUDE.md есть `LeadSource` enum). Стоит проверить что для footer-формы source указан правильно (например `footer` на всех страницах) — а лучше context-aware (`footer:cart`, `footer:thanks`).
