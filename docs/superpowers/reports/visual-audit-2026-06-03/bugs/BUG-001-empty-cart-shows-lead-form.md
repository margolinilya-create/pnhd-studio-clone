# BUG-001 — Пустая корзина показывает лид-форму вместо empty-state

| Поле | Значение |
|---|---|
| Severity | 🔴 Critical (блокирует funnel) |
| Страница | `/cart` (без позиций в sessionStorage) |
| Viewport | 375×812 mobile (вероятно и 768/1280, нужно подтвердить) |
| Браузер | Chromium 1.60 headless |
| Скриншот | [mobile-375/cart-empty-state.png](../../../../tests/visual-audit-2026-06-03/screenshots/mobile-375/cart-empty-state.png) |

## Что видно

На `/cart` без товаров пользователь видит:

1. Хедер сайта
2. Заголовок «Корзина» (H1)
3. **Пустоту** — никаких сообщений вроде «корзина пуста», «вы ничего не выбрали»
4. Под пустотой — карточку «ЗАПОЛНИТЕ ФОРМУ, МЫ СВЯЖЕМСЯ ДЛЯ КОНСУЛЬТАЦИИ» с полями имя / телефон / чекбокс согласия и кнопкой «ПРОКОНСУЛЬТИРОВАТЬСЯ»
5. Футер

## Ожидание

Согласно стандартам e-commerce и промту аудита:

- Дружественное сообщение «Корзина пуста»
- Главный CTA «Перейти в каталог» / «Вернуться к покупкам» → `/shop`
- (Опционально) популярные товары

Возможна альтернатива: redirect на `/shop` после гидрации (это, кстати, заложено в `CartClient` через `isHydrated && order.length === 0 ? router.push('/shop')` по CLAUDE.md §4 «Hydration race fix»). По текущему скриншоту редирект **не сработал** — пользователя оставили на `/cart`.

## Что сломалось в UX

- Юзер, открывший `/cart` через корзинную иконку или прямую ссылку при пустой sessionStorage, видит абсолютно непонятный экран — ему сразу предлагают заполнить форму без объяснения зачем
- Нет CTA вернуться в каталог — типичный e-com сценарий «упс, ничего не лежит — продолжить покупки» обрублен
- Лид-форма даже не имеет smart context (например «не нашли то что искали? оставьте контакт») — она generic «проконсультируйтесь»

## Воспроизведение

1. Открыть в чистом браузере `http://localhost:3000/cart` (`order_v3` в sessionStorage отсутствует)
2. Дождаться гидрации

## Возможные причины (для разработчика)

- В [src/app/(storefront)/cart/page.tsx](../../../../src/app/(storefront)/cart/page.tsx) или `cart-page/cart-client.tsx` логика «empty → redirect to /shop» либо не срабатывает, либо подменена на «empty → показать форму»
- `isHydrated` остаётся `false` (гидрация не завершилась) — тогда нужно показывать лоадер, а не форму

## Что предложить

- Если приоритет — конверсия: empty-state с большим CTA «Перейти в каталог» + 4-6 trending products
- Если приоритет — лиды: оставить лид-форму, но с явным заголовком «Корзина пуста — оставьте контакт, мы подскажем что выбрать» и кнопкой возврата в каталог сверху
